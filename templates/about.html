About the Model

Architecture & Results

NeuroScan AI uses a compact CNN trained on 3,000 real brain MRI images. Despite having only 11,137 parameters, it achieves 95.33% test accuracy thanks to OpenCV-based brain contour preprocessing that removes distracting black borders before each image enters the network.

Preprocessing (crop_brain_contour)

OpenCV Brain Isolation

The most impactful part of this pipeline is crop_brain_contour() — a function that uses OpenCV to detect and crop the brain region before resizing. This removes irrelevant black borders that would otherwise confuse the model.
